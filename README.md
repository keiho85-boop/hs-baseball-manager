# hs-baseball-manager

高校野球の監督として、選手の育成・試合の采配・学校経営を楽しむシミュレーションゲーム（開発中）。

スマホのブラウザで動くWebアプリ（PWA）です。ホーム画面に追加するとアプリのように使え、一度読み込めば通信なしでも遊べます。

## 開発の段階

1. 土台：選手の生成と能力値、部員一覧、年度の進行、セーブ ← いまここ
2. 試合エンジンとバランス検証ツール
3. 育成：すごろく練習、イベント、体力・ケガ
4. 大会：地方大会・全国大会、評判、スカウト、他校の成長
5. 演出：顔パーツ、試合画面、OBの息子、公開の準備

## 開発用コマンド

```
npm install
npm run dev       # 開発用サーバー
npm test          # ゲームの仕組みのテスト
npm run build     # 公開用のビルド
```

`main` ブランチに反映すると、GitHub Actions が自動でテスト・ビルドし、GitHub Pages に公開します。
