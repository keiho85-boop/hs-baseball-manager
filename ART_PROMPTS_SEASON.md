# 季節の背景（ホーム画面・6枚）

- **添付する見本：** `bg_ground_sunset.webp`（今の学校のグラウンドの絵。場所と画風をそろえるため）
- **サイズ：** 縦長 1024×1536
- ホーム画面では、この絵の上に盤面やボタンが重なります。中央から下は細かく描き込みすぎないように指定しています。

## 共通の前半（6枚とも、この文のあとに季節の文をつなげます）

```
Use the attached image as the reference for BOTH the place and the art style: the same small, worn-out public high school baseball ground with the old backstop net, the bench and the school building behind it, drawn with the same line art, coloring and painting style.
Vertical 2:3 background for a mobile game home screen. Wide, calm view of the ground from slightly above home plate. Keep the lower two thirds simple and softly detailed (bare dirt infield, grass, fence) because game panels will be placed over it. No people, no text, no letters, no numbers, no logos.
```
